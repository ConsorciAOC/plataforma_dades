## 1. Què és Gold

Gold és la capa de la plataforma amb les dades ja modelades, agregades i a punt per a analítica. És la que consumeixen els ens, ja sigui amb informes de Power BI, models semàntics, notebooks o connexió SQL a l'endpoint.

## 2. Quines taules hi ha

`lakehouse_gold` conté taules organitzades en esquemes. Els esquemes segueixen el patró `[organització]_[servei]`: `aoc_…` per a serveis propis del Consorci i `<font>_ddoo` per a dades obertes i fonts externes.

Les taules es distribueixen per tipus així:

| Prefix | Tipus |
|---|---|
| `ref_` | Referència |
| `fac_` | Fets |
| `agg_` | Agregació d'una taula de fets |
| `dim_` | Dimensió |
| `out_` | Sortida d'un procés o model |
| `mes_` | Taula mestra |
| `rel_` | Relació entre dimensions |
| altres | Sense prefix estàndard |

## 3. Diccionari de dades

Cada taula de Gold tindrà la seva fitxa amb aquesta estructura:

| Camp | Tipus | Descripció | Exemple |
|---|---|---|---|
| ⟨…⟩ | ⟨…⟩ | ⟨…⟩ | ⟨…⟩ |

**Convenció de noms de camp:** MAJÚSCULES amb prefix que indica el tipus.

| Prefix | Tipus de camp |
|---|---|
| `IDE` | Identificador |
| `DAT` | Data (precisió dia) |
| `HRS` | Data i hora |
| `TMS` | Timestamp / marca de temps |
| `DES` | Descripció |
| `FLG` | Booleà / flag |
| `IMP` | Import (+ sufix moneda) |
| `NUM` | Indicador numèric |
| `PER` | Percentatge |
| `URL` | Adreça web |
| `GEO` | Geolocalització |
| `ARR` | Array / llista de valors |

## 4. Freqüència d'actualització

Hi ha processos que s'actualitzen diàriament, setmanalment, mensualment i ad hoc (sota demanda).


## 5. Filtratge de dades

Les taules que contenen dades específiques d'organismes es filtren automàticament per l'identificador d'ens (`id ens`) corresponent.
